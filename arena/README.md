# 실시간 가위바위보 격투 테스트

`index.html`을 브라우저에서 엽니다. 중앙 FIGHT를 누르면 시작합니다. 오른쪽 니샤를 조작하며 상대 실비아의 준비 포즈와 공격 아이콘을 보고 1초 안에 대응합니다.

| 상대 공격 | 이기는 버튼 |
|---|---|
| 주먹 | 발차기 |
| 발차기 | 마법 |
| 마법 | 주먹 |

- 정답: 상대에게 16~18 피해, 내 마나 10 회복.
- 오답·시간 초과: 내 체력 14~16 감소.
- 같은 패: 양쪽 체력 2 감소.
- 방어: 마나 20 소모, 피해를 3으로 줄임. 마나가 부족하면 방어 버튼이 비활성화됩니다.
- 한 공방에는 한 번만 선택할 수 있습니다. 기본 공격은 마나가 없어도 가능합니다.
- 연속 정답마다 대응 시간이 0.04초씩 짧아지며 최소 0.65초입니다.
- 체력 0 또는 60초가 지나면 경기 종료. 시간 종료는 남은 체력으로 판정합니다.
- 왼쪽 아래: 효과음, 일시정지, 전체화면, 초기화. 종료 후 FIGHT로 재경기합니다.
- 키보드 A/S/D/F는 주먹/발차기/마법/방어, 스페이스는 시작/일시정지입니다.

기존 주점 및 첫 화면 시연판 브랜치는 유지했습니다. 아직 캐릭터 선택·대화·베팅·배당·벌칙을 연결하지 않은 전투 감각 테스트입니다. 대기 시 서로 다른 주기의 호흡을 적용했고, 캐릭터와 버튼 시트의 분리된 이웃 조각을 정리했습니다.

## 파일 구성

`arena-engine.js`는 판정·시간·체력·마나, `arena-data.js`는 표시 데이터, `arena.js`는 화면·입력·효과를 담당합니다. 외부 다운로드나 설치 없이 실행됩니다.

저장소 루트에서 `python3 arena/scripts/bundle.py`를 실행하면 에셋을 포함한 단일 HTML과 ZIP을 만듭니다.

## 검증

`node arena/tests/qte.test.cjs`로 세 상성, 오입력, 시간 초과, 무승부, 방어 및 마나 부족, 중복 입력·피해 방지, 일시정지, 승리·패배·시간 종료, 초기화를 검사합니다.

Playwright 브라우저 테스트: 서버를 띄운 뒤 `node arena/tests/qte.browser.cjs`를 실행합니다. 실제 버튼 터치, 한 경기 승리와 재시작, 일시정지, 단일 HTML의 오프라인 실행, 전체화면, 960×540 크기 조정, 에셋 누락·스크립트 오류를 확인합니다. `TAVERN_CHROMIUM`과 `ARENA_URL`로 테스트 환경을 지정할 수 있습니다. 실제 Android 기기에서의 난이도·반응 속도 평가는 아직 하지 않았습니다.

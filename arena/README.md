# 격투장 화면 테스트

`index.html`을 브라우저에서 열거나 `python3 -m http.server 8000` 실행 후 `/arena/`에 접속합니다. 별도의 설치나 빌드가 필요 없습니다.

오른쪽 네 버튼으로 주먹·발차기·마법·방어 연출을 확인합니다. 왼쪽 아래는 효과음, 일시정지, 전체화면, 다시 시작입니다. 키보드는 A/S/D/F, 스페이스로 일시정지합니다.

기존 주점과 분리된 16:9 경기 화면입니다. 제공된 콜로세움, 실비아·니샤 전투 포즈, HUD 시트를 사용했습니다. 캐릭터 선택, 대화, 베팅·배당·벌칙·가위바위보 판정은 아직 넣지 않았습니다. 현재 피해량과 상대 반격은 화면 효과를 확인하기 위한 시연 값입니다.

`arena-data.js`는 표시 데이터, `arena.js`는 시연 진행과 효과, `arena.css`는 배치를 담당합니다. `arena-preview.html`은 같은 화면을 에셋까지 포함한 단일 파일로 묶은 버전입니다.

단일 파일과 ZIP을 다시 만들려면 저장소 루트에서 `python3 arena/scripts/bundle.py`를 실행합니다.

검증: 브라우저에서 네 공격 효과, 일시정지 중 상태 유지, 재시작, 에셋 누락 없음, 960×540 화면 확대 비율, 모바일 터치 입력, 로컬 단일 HTML, 전체화면을 확인했습니다. 실제 Android 기기 검증은 아직 하지 않았습니다.

# 판타지 주점 v0.2 — 주점 시뮬레이션

## 실행

이 브랜치에는 v0.2의 분리된 코드와 에셋이 들어 있습니다. 저장소를 내려받은 뒤 `index.html`을 Chrome 또는 Edge에서 여세요. 인터넷, 서버, 설치가 필요 없습니다. 화면은 16:9 가로로 맞춰 표시됩니다. 이미지 내장 단일 HTML은 별도 배포 파일입니다.

Android 파일 관리자의 HTML 미리보기가 스크립트를 실행하지 않으면 브라우저로 열어 주세요. 실제 Android 기기의 파일 열기/터치감은 사용 기기에서 확인해야 합니다. APK는 이 패키지에 포함하지 않았습니다.

수정용 프로젝트는 이 브랜치의 루트 폴더입니다. `index.html`을 브라우저로 열면 실행됩니다. 선택적으로 해당 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`으로 접속할 수 있습니다.

## 한 판 테스트 순서

1. 처음 펼쳐지는 장부의 **직원** 항목에서 오늘 출전할 6명을 선택하세요. 기존 출전 직원을 제외한 뒤 다른 직원을 추가할 수 있습니다. 종업원은 총 10명입니다.
2. **영업 시작**을 누르세요. 영업시간은 3분이며, 시간이 끝나도 기존 손님은 마저 응대합니다.
3. 하단 오른쪽 **입장 대기 손님 한 칸**을 누르고 **빈 테이블로 안내한다**를 선택하세요. 빈 테이블을 누르면 착석합니다.
4. 하단 종업원을 누르고 **담당 테이블을 선택한다**를 고르세요. 종업원이 없는 손님 카드에 궁합과 표정이 미리 표시됩니다. 테이블을 눌러 확정하세요.
5. 손님 초상화가 **음료·음식·주류·서비스·연장·계산 아이콘**으로 바뀌면 해당 테이블을 누르세요. 작은 창에서 메뉴나 응대 방법을 선택하세요.
6. 대응창, 장부, 손님/직원 정보창, 배치 선택 중에는 **영업시간·모든 손님의 진행·대기시간·직원 체력이 함께 일시정지**됩니다. 따라서 창을 연 뒤 차분히 선택해도 됩니다.
7. 계산 요청에서는 배웅 방법을 선택합니다. 손님이 퇴장하면 자리가 비고 담당 직원이 대기로 돌아옵니다.
8. 마감 후 마지막 손님이 퇴장하면 **책 장부의 결산**이 열립니다. **다음 날 준비**로 자금과 남은 재고를 이어서 운영하세요.

열린 대응창을 닫으면 해당 요청은 그대로 남아 있습니다. 대응창 바깥에서 오랫동안 방치하면 만족도가 조금씩 낮아지고 요청을 취소할 수 있습니다. 요청이 남은 동안의 시간은 대응창을 열면 멈춥니다. 수동 일시정지는 상단 버튼으로 별도 해제합니다. 다른 앱으로 이동하면 자동 일시정지됩니다.

## 실제 선택과 운영

- **음료·음식·주류:** 가격, 재고, 맛, 손님 예산을 보고 선택합니다. 메뉴별 실제 재고가 1개씩 줄고 이용 금액과 원가가 기록됩니다. 취향에 맞는 메뉴는 만족도가 상승하고 맞지 않는 메뉴는 낮아집니다.
- **서비스:** 이야기, 흥겨운 건배, 다정한 응대, 식탁 정돈 중 선택합니다. 손님의 선호와 담당 종업원의 해당 능력이 결과에 반영됩니다. 행동별 체력 소모도 다릅니다.
- **연장:** 수락하면 접객료 40G와 추가 주류·서비스가 이어집니다. 마감 후와 만족도 55% 미만일 때는 수락할 수 없습니다. 거절하면 다음 계산 단계로 넘어갑니다.
- **계산:** 기본 배웅 또는 10G의 작은 선물과 배웅을 선택합니다. 만족도가 높으면 팁이 붙습니다.
- **품절:** 요청창에서 장부의 재고 항목으로 이동해 발주할 수 있습니다. 장부를 닫으면 원래 요청창으로 돌아옵니다. 또는 품절을 안내해 다음 단계로 넘어갈 수 있습니다.

직원의 일일 급여는 각 70G입니다. 이름은 확정되지 않아 종족명으로 표시합니다. 가격·능력·시간·수량은 v0.2 테스트 수치로 데이터 파일에서 조정할 수 있습니다.

## 장부

- **직원:** 10명 정보, 큰 일러스트, 능력, 현재 체력, 급여, 출전 6명 선택. 영업 중에는 출전 변경을 막고 상세 정보만 표시합니다.
- **메뉴:** 음료 3종, 음식 4종, 주류 3종. 기존 메뉴 아이콘, 판매가, 원가, 맛, 설명, 재고 표시.
- **재고:** 보유량, 부족 표시, 1/5/10개 발주. 발주 금액을 현금에서 차감하고 즉시 입고합니다. 발주 대기시간은 이번 버전에 없습니다.
- **결산:** 매출, 사용 재고 원가, 급여, 선물 비용, 영업 이익, 발주 지출, 남은 재고 가치, 자금, 손님 수/만족도, 직원별 접객·제공·매출.

처음에는 현금 3,000G와 각 메뉴 4개가 준비되어 있습니다. 초기 재고 가치는 1,184G이며 준비된 재고로 취급합니다. 발주는 현금 지출, 제공한 재고는 사용 원가로 구분합니다.

**영업 이익 = 매출 − 사용 재고 원가 − 급여 − 선물 비용**

**마감 현금 = 시작 현금 + 매출 − 발주 지출 − 급여 − 선물 비용**

**마감 재고 가치 = 시작 재고 가치 + 발주 금액 − 사용 재고 원가**

재고를 사 둔 금액과 오늘 사용한 재고 원가를 이중으로 차감하지 않습니다. 팁은 매출에 포함됩니다.

- 전달한 `Pictures02.zip`의 6테이블 배경 3종과 손님 30명×표정 5종, 종업원 10명×표정 5종을 실제 사용합니다.
- 요청이 생기면 손님 초상화 자리를 해당 요청 아이콘으로 바꿉니다.
- 하단 중앙~오른쪽은 종업원 6칸과 대기 손님 1칸입니다. 왼쪽 하단에는 고정 UI를 두지 않고 큰 일러스트 등장 공간으로 사용합니다.
- 큰 일러스트와 대화는 인사·응대·서비스·계산 때 표시합니다.
- 직원·메뉴·재고·결산은 전달한 책 이미지 위에 실제 UI를 얹습니다.
- 처음 전달한 압축파일의 메뉴·서비스·계산·연장·일시정지 아이콘과 기존 큰 일러스트를 활용합니다.
- **SD 캐릭터는 이번 화면에 사용하지 않습니다. 새 이미지는 생성하지 않았습니다.**

## 구조·확장

- `js/data.js`: 직원, 능력, 메뉴, 손님 선호, 서비스 선택지, 시간/비용
- `js/engine.js`: DOM과 분리한 손님/요청 상태, 메뉴 선택, 재고, 일시정지, 결제·회계·다음 날·저장 데이터
- `js/render.js`: 실제 에셋 렌더링, 화면 입력, 테이블 카드, 작은 대응창, 장부, 대화
- `style.css`: 논리 1280×720 화면 및 16:9 자동 축소
- `assets/`: 원본을 자르거나 축소한 파생 이미지, 기존 한글 폰트
- `tests/engine.test.cjs`: 의미 있는 핵심 흐름 검사

직원 데이터는 향후 레벨·액세서리·친밀도·개인 이야기와 기본 접객복/고급 파티 드레스/수영복/평상복의 **4종 의상**을 추가할 수 있게 유지했습니다. 이번 버전에서 해당 성장 기능, 특별 서비스 피버타임, 진상 퇴치, 신규 특수 메뉴는 구현하지 않았습니다.

## 저장과 기존 작업

마감 후와 다음 날 준비/준비 중 발주·출전 변경 시 현재 브라우저의 로컬 저장소에 저장합니다. 다음에 열면 다음 날 준비부터 이어집니다. **영업 도중의 저장·불러오기, 클라우드 동기화는 지원하지 않습니다.** 브라우저/파일 경로가 달라지면 저장 위치도 달라질 수 있습니다.

v0.1 파일은 별도로 보존했습니다. 이 저장소의 `codex/baseline-v0.2` 브랜치는 현재 v0.2 기준 버전입니다. 이후 합의한 변경 사항은 `docs/NEXT_VERSION.md`에 기록했으며 아직 이 게임 코드에는 반영하지 않았습니다.

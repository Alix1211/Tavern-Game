# 소품 버블팡 (Bubble Pang) v0.2.1

이 디렉터리는 Tavern-Game 본편과 분리된 독립 실행형 미니게임 시제품입니다. 현재 본편에 임포트/연결하지 않았습니다.

## 실행
- `index.html`을 브라우저에서 엽니다.
- HTML 파일 안에 배경, 구슬, 소품, 캐릭터 이미지가 모두 내장되어 있으므로 별도 에셋 경로가 필요 없습니다.
- 16:9 가로 화면 기준이며, 모바일 가로 화면 크기에서도 레이아웃이 들어오도록 조정했습니다.

## 동작
- 같은 소품 버블 3개 이상 연결 시 터짐; 연결이 끊긴 버블도 낙하 및 수집.
- 5발 발사 후 **해당 발사체가 보드에 도착한 뒤** 새 줄이 내려옵니다.
- 실패선에 닿으면 게임오버. 제한 시간 및 난이도 상승은 없습니다.
- 종류별로 **10개 또는 20개 버블**을 모으면 소품 1개가 됩니다.
- 소품 보유량과 수집 중인 조각 개수는 로컬 스토리지에 저장합니다.
- 왼쪽은 직원 이미지/수다, 가운데는 플레이, 오른쪽은 수집 UI입니다.

- 모모, 루비아, 니샤, 브리카, 피피, 실비아 총 6명 이미지가 이 버전 왼쪽 패널에 표시됩니다.
- 다른 종업원은 본편 합류 전이며 향후 필요 시 기존 에셋으로 연결합니다.

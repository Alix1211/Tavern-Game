# v0.9 UI

원본 7개를 복구하고 고유 소스 6개에서 투명 에셋 40개를 추출했습니다. 4종(1)과 -3은 동일 구성입니다. manifest.json에 출처와 픽셀 좌표를 기록합니다. 원본을 수정하거나 새 이미지를 생성하지 않았습니다.

decor.css에서 패널과 소품을 적용합니다. 테이블 6개·직원 6칸·손님 1칸과 드래그 좌표를 유지하고 장식은 pointer-events:none으로 입력을 방해하지 않습니다. 좁은 패널은 border-image 65픽셀 슬라이스로 가장자리를 보존합니다. 커튼 간판도 시각 효과입니다.

이번 작업은 디자인 적용입니다. 일반 서비스 자동화와 신규 SD 슬랩스틱은 미구현입니다.

# 다음 버전의 기획 메모

이 파일은 v0.2 이후 대화에서 합의하거나 검토한 방향을 기록합니다. 현재 브랜치의 게임 코드에 구현된 기능 목록이 아닙니다.

## 우선 반영할 화면과 구매 규칙

- 제공한 프레임·게이지·버튼·아이콘·장부 에셋을 최대한 활용해 디자인 개선.
- 큰 캐릭터 일러스트는 원본을 잘라 저장하지 않고 확대·위치 조정. 화면 아래 경계가 무릎 위/허벅지 부근에 오도록 배치하며 얼굴과 상체를 크게 보여준다. 화면 밖 부분은 클리핑한다.
- 가로 모드 고정. 테스트 빌드 상단에 전체화면 아이콘을 반드시 표시. 전체화면 진입 후 가로 방향 잠금을 시도하고 미지원 환경에서는 회전 안내.
- 영업 전 시장 구매는 정상 매입가. 영업 중 긴급 발주는 심부름값 포함 정상 매입가의 2배. 판매가는 유지. 비용과 총액을 구매 전에 표시.

## 경영과 육성

- 물장사 아일랜드의 주점 경영 + 프린세스 메이커의 직원 육성.
- 종업원 10명 중 6명 접객, 나머지 4명은 교육/휴식으로 교대 육성하는 안을 검토 중.
- 교육 6종은 영업이 끝난 주점, 화장실 청소, 별실, 침실, 서재, 연병장 배경을 사용. 교육별 상승 스탯만 둔다. 시장은 구매, 진료실은 치료 배경으로 별도 사용.
- 교육은 돈을 사용해 빠르게 성장. 접객은 느리게 성장하며 일부 스탯은 내려갈 수도 있다. 실제 스탯·특성·수치·교육별 대응은 미정.
- 영업에는 초상화 카드 사용. 직원 SD는 교육 장면에서 뛰기·청소·독서 등의 간단한 코드 애니메이션에 사용. 남성 SD는 시장 NPC, 교관/연습 상대, 생활 이벤트 조연 등에 활용.
- 의상은 기본 접객복, 고급 파티 드레스, 수영복, 평상복의 4종.

## 손님 궁합과 서비스

- 손님을 누르면 원하는 조건 세 축을 확인. 직원 선택 시 각 조건의 적합 여부를 표시.
- 접객 성향 S/M, 외모 청순/귀염/섹시/큐티, 분위기 활달/차분/지성을 검토 중. 귀염/큐티 중복, 지성 유지, 고정 특성과 성장 능력의 구분은 아직 확정되지 않았다.
- 조건 1개 적합: 평범(?) 서비스, 2개: 특별 서비스, 3개: 완벽 서비스. 단계마다 선택지·추가 금액·스탯 상승 내용과 양을 다르게 설계. 실제 수치는 미정.
- 일반 손님은 최소 1회 연장 후, 단골 지명 손님은 선호 직원 지명과 간단한 주문 후 특별 서비스 요청 가능. 직원 능력과 손님 취향 조건은 유지.
- 서비스는 커튼 뒤에서 진행하며 안쪽을 묘사하지 않는다. 커튼 시트, 하트·소품 아이콘, 매출과 체력 변화로 표현.
- 종족별 이름은 은유적이고 코믹하게. 예: 용족의 따뜻한 손길, 하피의 깃털 마사지, 슬라임의 촉촉 보습 세안, 수인족의 산책 갈까?
- 음성과 효과음은 플레이어가 클릭했을 때만 재생. 자동 반복/중첩 재생 금지. 확보한 음원은 아직 이 저장소에 전달되지 않았다.

## 대사 톤

- 성인 등장인물에게 이 세계의 접객 문화는 평범한 일상. 자연스럽고 뻔뻔한 코미디.
- 공무원식 안내문, 극존칭, 불필요한 세계관 해설을 지양. 성격·접객 역할·친숙함에 따른 호칭과 짧은 받아치기, 과장된 감탄사와 종족별 농담을 활용.
- 교육으로 접객 실력은 성장하지만 캐릭터의 개성은 유지한다. 용족은 여왕님다운 접객을 익히며, 어울리지 않는 역할 때문에 영업 가구를 파괴하는 식의 연출은 피한다.


## v0.3 적용 완료 (2026-10-12)

캐릭터 확대/화면 밖 배치, 전체화면 아이콘/가로 안내, 시장 정상가/운영 중 긴급 발주 2배, 시장·진료실 기존 배경을 적용했습니다. 진료실의 체력 회복은 테스트 수치(+30 하루 휴식, 부족 체력 1당 1G 치료)입니다. 나머지 교육·특성·커튼·서비스·효과음은 향후 작업입니다.

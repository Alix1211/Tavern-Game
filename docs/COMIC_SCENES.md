# v0.10 주문·역할·소동 연결

## 구현

- 일반 접객 요청은 손님이 원하는 능력치에 맞는 기존 응대 로직으로 자동 처리합니다. 기존 네 가지 일반 서비스 선택지는 UI에서 제거합니다. 선택 가능한 특별 코스가 있는 요청은 남겨 점주가 고릅니다. 일반 응대로 넘어가는 한 가지 버튼은 유지합니다.
- 각 직원의 일반 접객 이름·손님 요청·직원 반응·종족 동작을 comic-scenes-data.js에서 연결합니다. 특별 코스 도입은 실제 선택한 기존 코스명과 대사를 사용합니다. 기본 S4/M4/미발현2, 브리카의 호탕한 성격은 유지합니다.
- 커튼은 기존 테이블별 32초입니다. 클릭하면 소리와 커튼 흔들림에 SD 반응이 추가됩니다. 용족은 채찍 백만 대, 거미여인은 거미줄 백만 겹, 라미아는 꼬리 백만 바퀴, 다크엘프는 명령 백만 개처럼 과장된 반응을 구분합니다. 숫자는 대사이며 실제 타격 수·요금이 아닙니다.
- 머리 내밀기, 대각선 발사/회수, 5배 카메라 확대와 압축 충돌, 좌우 질주, 종잇장 납작/복원, 슬라임 퍼짐/탄성 복원, 거미줄 고치 회전, 깃털 흩날림, 회전, 건배 반동, 굳었다 풀림, 엘프 인사 동작을 공통 시스템으로 재사용합니다. S/M은 반응과 복귀 대상에 반영합니다.
- 효과 레이어는 입력을 받지 않습니다. 큰 동작은 한 번에 하나, 작은 동작 포함 최대 두 개입니다. 연속 클릭은 진행 중 동작을 계속 초기화하지 않습니다. 자동 연출은 기존 클릭 전용 SFX 규칙을 유지하여 무음입니다.
- 게임 정지/메뉴/드래그 시 연출 시간도 정지합니다. 테이블 담당 변경, 계산, 영업 종료 시 연출을 제거합니다. UI와 다른 테이블 로직은 유지합니다. 연출은 추가 요금·재고·XP·피로를 만들지 않습니다.
- 하단 직원 초상화의 기존 소품과 새 장식 레일을 모두 제거합니다.

## 에셋과 구조

남성 SD는 사용자가 이미 제작한 5개 시트에서 9종 × 정면/좌/우 27개를 추출했습니다. 30개 손님 초상화에 직업에 맞춘 SD 유형을 재사용합니다. 30명 개별 SD를 새로 생성하지 않았습니다. manifest에 원본과 위치를 기록합니다. 직원은 기존 종족 SD를 사용합니다. 거미줄 등 간단한 부가 효과는 CSS입니다.

comic-scenes.js는 시각 효과 수명/경로만 관리합니다. 기존 special-engine.js는 일반 응대 자동화와 기존 비용 처리 연결을 맡습니다. 이동/회전/확대/압축은 공통 보간으로 계산합니다.

## 검증과 한계

Node에서 자동 응대 단일 비용, 다른 패널 보존, 특별 서비스 선택 유지, 클릭에 따른 추가 과금 없음, 32초 복귀를 검사했습니다. 기존 재고/포도주/회계/저장/육성/직원 교체 검사도 통과했습니다.

브라우저에서 11개 과장 동작의 이동/변형·정지·제거를 확인했고, 자동 응대, 실제 특별 코스 터치, 종료 후 복귀, 960×540, 하단 소품 제거, JS/이미지 오류를 검사했습니다. 녹화는 실제 렌더러와 입력을 사용합니다. 고단계 확인용으로 녹화의 직원 능력치는 Lv.6/90으로 준비했으며, 본편 해금 조건은 변경하지 않았습니다. 녹화 영상은 무음입니다. 본편 클릭 SFX는 유지됩니다.

실제 Android 성능·재미 평가는 사용자 확인이 필요합니다. 침실/체험학습실 별도 시스템과 버블게임 통합, 모든 72코스의 개별 고유 동작은 이번 범위에 없습니다. 코스들이 공통 패턴을 재사용합니다.
